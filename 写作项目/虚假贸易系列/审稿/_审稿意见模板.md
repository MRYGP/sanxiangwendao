# 审稿意见模板

> 复制本模板为 `审稿/NN-审稿意见.md`，填写第 NN 篇《篇名》的审稿意见。
> 分两部分：研究审查（研究笔记完成后）+ 稿件审查（初稿完成后）。

## 第一部分 · 研究审查（研究笔记完成后）

- [ ] 来源表填满、可信度标注清楚？
- [ ] 研究够不够用？缺什么？
- [ ] 哪些来源不可靠、需要替换？
- [ ] 事实与判断是否已分开？

**结论**：够用 / 需补充（列出补充项）

## 第二部分 · 稿件审查（初稿完成后）

### 1. 事实
- [ ] 每个数字、案例、政策都有可靠来源，和原文一致？

### 2. 视角
- [ ] 真的站在这个角色的座位上，而不是换个标题重复总论？

### 3. 逻辑
- [ ] 好处、代价、动机能否推出"为什么停不下"？

### 4. 边界
- [ ] 有没有把判断写成定论？
- [ ] 有没有在描述机制时滑向"教人怎么做"？

### 5. 一致
- [ ] 术语、光谱分类、核心命题与框架及前几篇一致？

### 6. 可读
- [ ] 第一层读者（实操者）能否读懂？
- [ ] 最终读者（政策制定者）能否读下去？

## 第三部分 · 结论

- [ ] 通过
- [ ] 小修（列出修改点）
- [ ] 需裁决（列出争议点，交松阳定）
