## 二、单篇流程（写完一篇再开下一篇）

> 研究阶段先读 `研究/_公共事实库.md`，能引用的事实直接引用编号（如 F-03），不要重复检索。

| 步骤 | 谁来做 | 产出 | 完成标志 |
|------|--------|------|----------|
| 1. 研究 | DeepSeek（联网） | `研究/NN-研究笔记.md` | 来源表填满，事实与判断已分开 |
| 2. 研究审查 | Claude | `审稿/NN-审稿意见.md` 第一部分 | 研究够不够用、缺什么、哪些来源不可靠 |
| 3. 写初稿 | DeepSeek | `稿件/NN-篇名.md` | 按框架里的统一骨架写完 |

**进度更新规则**：哪一方完成哪个步骤，就由哪一方在 `进度.md` 里把对应格子改为 ✅。DeepSeek 负责研究、初稿、修订三栏，Claude 负责研究审查、审稿两栏，定稿一栏由用户来改。

## 三、研究笔记的要求（第 1 步）

每份研究笔记必须包含四部分：

- **来源表**：标题、链接、发布机构、发布日期、可信度（官方 / 权威媒体 / 一般媒体 / 自媒体）
- **事实清单**：每条事实都标出对应的来源编号；没有来源的不准写成事实
- **观点与争议**：不同的说法分别是谁说的
- **缺口**：查不到、查不实、还需要人工确认的内容

**来源优先级**：监管机构原文（国资委、证监会、人民银行、金融监管总局、法院）> 上市公司公告 > 权威媒体 > 行业研究 > 自媒体。

## 四、DeepSeek 提示词模板

### 研究阶段

```
读取 写作项目/虚假贸易系列/00-系列框架.md 和 写作流程.md。
现在研究第 NN 篇《篇名》，视角是【角色】。
请联网搜索，围绕框架中这一篇的要点（好处、代价、衍生业务、为什么停不下、出口）收集资料。
按"写作流程.md"第三节的四部分格式，输出到 研究/NN-研究笔记.md。
只写有来源的事实；判断和推测单独标注。不要开始写正文。
```

### 写作阶段

```
读取 00-系列框架.md、研究/NN-研究笔记.md、审稿/NN-审稿意见.md（研究审查部分）。
按框架里的"每篇统一骨架"写第 NN 篇，输出到 稿件/NN-篇名.md。
要求：大白话，像带徒弟的 CEO 在说话；事实只用研究笔记里有来源的，并在文中标注来源编号；
判断要写成判断；只描述机制，不写操作方法；结尾留一个问题给读者。
```

### 修订阶段

```
读取 稿件/NN-篇名.md 和 审稿/NN-审稿意见.md。
逐条修订，并在审稿意见文件末尾追加"修订回应"：每条写"已改 / 未改及原因"。
```

## 五、Claude 审稿的标准

- **事实**：每个数字、案例、政策是否都有可靠来源，和原文是否一致
- **视角**：这一篇是不是真的站在这个角色的座位上，而不是换个标题重复总论
- **逻辑**：好处、代价、动机能否推出"为什么停不下"
- **边界**：有没有把判断写成定论，有没有在描述机制时滑向"教人怎么做"
- **一致**：术语、光谱分类、核心命题是否和框架、前几篇一致
- **可读**：第一层读者（实操者）能不能读懂，最终读者（政策制定者）能不能读下去

## 六、全系列总修订（全部定稿后）

- **术语统一**：托盘、空转走单、循环贸易、光谱等用法前后一致
- **去重**：同一个机制只在一篇里讲透，其他篇只引用
- **交叉引用**：各篇之间互相指向
- **事实复核**：时效性强的政策和数字在发布前再核一遍
- **主线检查**：从 00 读到 11，"讲清楚 → 视角 → 案例 → 路线 → 总结"这条线是否顺
- **标题与发布顺序最终确定**
