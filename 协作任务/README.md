# 协作任务

本目录用于 Claude Desktop、Codex 和松阳之间传递可执行任务。

## 状态目录

- `待执行/`：Claude/松阳已经确定方向，等待 Codex。
- `执行中/`：Codex 已接单并开始处理。
- `待验收/`：Codex 已完成，等待 Claude/松阳读取实际文件验收。
- `已完成/`：验收通过，任务归档。

## 命名规则

```text
TASK-YYYYMMDD-NNN-简短标题.md
```

例如：

```text
TASK-20260713-001-修订认知流变学摘要.md
```

## 使用方法

1. Claude 或松阳用 `任务单模板.md` 创建任务。
2. Codex 接单时，将任务移到 `执行中/`。
3. Codex 完成修改和验证后，填写执行报告并移到 `待验收/`。
4. Claude 必须读取实际目标文件进行验收。
5. 通过后移到 `已完成/`；小修则写清修订项并退回 `待执行/`。

不要把聊天记录直接当任务单。任务单必须脱离原聊天也能执行。
