## 如何使用

### 想理解整个体系

先读 DOC-D008 核心框架，再按 [学习路径](rag-index/learning-paths.md) 选择一条与你当前问题相符的路径。

### 想查找某个理论

1. 在 [文档ID映射表](rag-index/doc-mapping.md) 中按标题、主题或 ID 定位。
2. 阅读对应正文。
3. YAML 只用于检索和路由，不替代正文。

### 想新增或修订文档

1. 先读 `AGENTS.md` 与相关 SOP。
2. 涉及跨文档或跨库时先读 `_cross_refs.yaml`；涉及 `D:\SK\theory` 时再读其 `_README-本目录状态.md`。
3. 查重并确定知识身份、应用域和成熟度。
4. 同步检查正文、YAML、映射、学习路径和 README。
5. 运行与风险相称的验证。

### 想维护 RAG

- [索引更新检查清单](rag-index/索引更新检查清单.md)
- [RAG索引重建操作指南](99-gongjuSOP/知识库/RAG索引重建操作指南.md)
- `python scripts/validate_only.py`：检查 DOC_MAPPING、YAML 和跨库本地 ID。
- `python scripts/build_index.py`：重建向量索引，执行前确认环境和成本。
